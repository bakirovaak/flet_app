# HabitFlow — трекер полезных привычек (Flet)

Минималистичное кроссплатформенное приложение на Python + Flet.

## Возможности
- Добавление привычек через текстовое поле (Enter или кнопка «+»)
- Отметка выполнения за сегодня одним тапом/кликом
- Автоматический подсчёт текущей серии дней подряд (streak) 🔥
- Прогресс-бар «выполнено X из Y» на сегодня
- Удаление одной привычки или всех сразу (с подтверждением)
- Кнопка «Сбросить сегодня» — снимает отметки за текущий день, не трогая историю
- Данные сохраняются локально через `page.client_storage` (асинхронно, без
  зависаний интерфейса) — работают и переживают перезапуск на Web, Desktop и Mobile
- Тёмная минималистичная тема, адаптивная верстка (ResponsiveRow) — одинаково
  хорошо выглядит и на телефоне, и на широком окне ПК

## Установка

```bash
pip install -r requirements.txt
```

(или просто `pip install flet`)

## Запуск

**Как десктопное приложение (нативное окно):**
```bash
python main.py
```

**В браузере:**
```bash
flet run --web main.py
```

**Горячая перезагрузка при разработке:**
```bash
flet run -d main.py
```

**Сборка под Android / iOS** (требует настроенного Flutter SDK):
```bash
flet build apk      # Android
flet build ipa       # iOS
```
Подробности — в официальной документации Flet: https://flet.dev/docs/publish

## Структура проекта

```
habit_tracker/
├── main.py            # всё приложение: модель Habit, HabitStore (хранение), HabitApp (UI)
├── requirements.txt
└── README.md
```

Код организован в виде трёх классов (ООП), поэтому расширять легко:
- **Habit** — модель привычки и её логика (streak, отметка выполнения)
- **HabitStore** — асинхронное сохранение/загрузка (сейчас — client_storage,
  при желании можно заменить на SQLite/сервер, не трогая UI-код)
- **HabitApp** — построение интерфейса и обработчики событий
